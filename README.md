# Mini Computer Simulator in C

A modular **Mini Computer Simulator** implemented in **C**, capable of compiling a simple assembly-like language into bytecode and executing it using a simulated processor architecture.

The project demonstrates fundamental concepts of **Computer Organization and Architecture**, including instruction encoding, memory organization, registers, and the instruction execution cycle.

---

## Features

* Custom assembly-like instruction set
* Compiler to convert source code into bytecode
* Separate instruction and data memory
* Register-based processor simulation
* Execution of arithmetic and memory operations
* Modular implementation using multiple source files
* Execution trace for debugging and visualization

---

## Project Architecture

```
                Source Program
                     │
                     ▼
                Compiler Module
                     │
             Generates Bytecode
                     │
                     ▼
          Instruction Memory (256 Bytes)
                     │
                     ▼
              Processor Simulator
          ┌─────────────────────────┐
          │  Fetch                  │
          │  Decode                 │
          │  Execute                │
          │  Memory Access          │
          │  Register Update        │
          └─────────────────────────┘
                     │
                     ▼
             Data Memory (256 Bytes)
```

## Supported Instructions

| Instruction | Description                           |
| ----------- | ------------------------------------- |
| LOAD        | Load data from memory into a register |
| STORE       | Store register value into memory      |
| ADD         | Addition                              |
| SUB         | Subtraction                           |
| MUL         | Multiplication                        |
| DIV         | Division                              |
| MOV         | Copy register values                  |
| READ        | Read input                            |
| WRITE       | Display output                        |

---

## Instruction Execution Cycle

For every instruction, the simulator performs:

1. Fetch instruction from Instruction Memory
2. Decode opcode and operands
3. Execute the instruction
4. Access memory if required
5. Update registers
6. Proceed to the next instruction

Execution information is printed to the console for easier debugging and understanding.

---

## Memory Organization

### Instruction Memory

* Size: **256 Bytes**
* Stores generated bytecode

### Data Memory

* Size: **256 Bytes**
* Stores variables and data used during execution

### Registers

General-purpose registers are used for arithmetic operations and temporary storage during execution.

## How to Build

Compile using GCC:

```bash
gcc main.c compiler.c processor.c memory.c -o simulator
```

Run:

```bash
./simulator
```

---

## Example Workflow

1. Write an assembly program in `source.txt`
2. Compile it into bytecode
3. Load bytecode into Instruction Memory
4. Load initial data into Data Memory
5. Execute the program
6. Observe the execution trace and final results
